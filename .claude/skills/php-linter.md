# Skill: php-linter

## Descrição

Executa a checagem de erros de sintaxe nos arquivos PHP antes de salvar alterações.

## Comandos de Execução

- Validar arquivo principal do FrontEnd: `php -l FrontEnd/index.php`
- Validar scripts do BackEnd: `php -l BackEnd/`
